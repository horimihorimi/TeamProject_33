# Project E33

- Unreal Engine 5.3 기반의 Clair Obscur: Expedition 33 모작 프로젝트입니다. 학습을 목적으로 진행한 팀 프로젝트이며, 사용된 일부 에셋은 본 저장소에 포함되어 있지 않습니다.
- 본 저장소에는 원본 프로젝트에서 제가 직접 작성한 코드만 포함되어 있으며, 해당 코드는 `Workspace/KHB`에 정리되어 있습니다.

## 프로젝트 소개

- 장르: 턴제 멀티플레이 전투
- 개발 기간: 2026.05.21 ~ 2026.06.21
- 팀 구성: 3인 팀 프로젝트

## 영상 / 발표 자료

## 팀원 소개

- 최영우: 전투 카메라·연출·전투 UI
- 김현빈: 멀티플레이 접속 · 던전 전환 · 턴제 전투 · QTE 시스템
- 최우석: 몬스터 AI·전투 컴포넌트·애니메이션 노티파이

## 담당 역할

**멀티플레이 접속 시스템**

- 메인 메뉴·로비 흐름 및 서버 목록 구현
- 호스트·클라이언트 접속 상태 처리
- 로비 플레이어 및 캐릭터 관리

**던전 전환 시스템**

- 로비와 던전 간 레벨 전환 흐름 구현
- 멀티플레이 레벨 스트리밍 및 언로드 처리
- 던전 입장·퇴장 상태 관리

**턴제 전투 시스템**

- BattleManager·TurnManager 기반 턴 진행 및 전투 상태 관리
- 턴 진행 순서 UI 연동
- 패링·카운터 시스템 연계

**QTE 시스템**

- 공격 타이밍 기반 QTE 구현
- 애니메이션과 QTE 시작 시점 연동
- QTE 결과에 따른 전투 흐름 처리
